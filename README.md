# قريب — منصة الولاء والضيافة حسب القرب

نموذج أولي تفاعلي (MVP) لمنصة تسويق بالقرب وبطاقات ولاء ذكية، مصممة للمقاهي والمطاعم والمحلات في ليبيا.

**جرّب النموذج مباشرة:** https://omarkraym.github.io/qareeb-mvp/

---

## الفكرة

بدل الخصومات الثابتة المعتادة، تعتمد المنصة على لحظات ثقافية ليبية:

| المحفّز | متى يعمل | ماذا يصل للزبون |
|---|---|---|
| **الكرم والضيافة اللحظية** | الزبون مسجّل ودخل نطاق المحل، والمحل **هادئ** | ضيافة مجانية لمدة محدودة (مثلاً مكياطة مع أي طلب لمدة 15 دقيقة) |
| **حالة الزحمة** | المحل **زحمة** | لا عرض مجاني، بل دعوة للطلب المسبق عبر واتساب لتخطّي الطابور |
| **تجمع الشلة/العائلة** | زبونان مسجّلان يمرّان قرب المحل معاً | العرض يترقّى تلقائياً لعرض جماعي (مكياطتين + حلويات) |

## ما يحتويه النموذج

النموذج صفحة واحدة بواجهتين متزامنتين:

### 1. لوحة تحكم صاحب المحل
- **إعداد المحل:** الاسم، نصف قطر النطاق (50–500 م)، وموقع المحل (يدوي أو من GPS).
- **رمز QR ديناميكي** للطاولات والواجهة، مع زر تنزيل للطباعة.
- **رادار مباشر** يرسم النطاق وموقع الزبون (وصديقه في وضع الشلة) ويعرض المسافة المحسوبة.
- **زر الحالة السريع للكاشير:** «هادئ - وقت ذهبي» أو «زحمة».
- **محرر الرسالة التلقائية** مع متغيرات: `{customer_name}` `{store_name}` `{store_status}` `{offer}` `{offer_expiry}` `{distance}` `{friend_name}`، ومعاينة فورية.
- **إحصاءات:** عدد الزبائن، التنبيهات المرسلة اليوم، العروض المستخدمة، ونسبة التحويل.
- **جدول الزبائن (CRM)** وسجل التنبيهات المباشر مع حالة كل عرض (نشط/استُخدم/انتهى/لم يُرسل).

### 2. محاكي هاتف الزبون
- **مسح الرمز ← تسجيل سريع** (الاسم + رقم ليبي يبدأ بـ 091 أو 092 أو 094). يقبل أيضاً `+218` والأرقام العربية.
- **بطاقة ولاء رقمية** بنمط Apple/Google Wallet مع أختام الزيارات ورمز العضوية.
- **ربط واتساب** مع رسالة ترحيب.
- **شاشة القفل:** إشعار فوري + رسالة واتساب عند دخول النطاق، مع صوت واهتزاز.
- **عد تنازلي حي** لمدة العرض، وزر لاستخدامه عند الكاشير (يزيد عدد الزيارات).

### 3. أدوات المحاكاة
- شريط **المسافة عن المحل (0–1000 م)**.
- زر **«محاكاة مرور الزبون بجانب المحل»**: يقترب الزبون من بعيد ثم يبتعد.
- مفتاح **«محاكاة مرور صديقين مسجلين معاً»**.
- مفتاح **GPS الحقيقي** لقياس المسافة الفعلية بينك وبين المحل.

## طريقة التجربة (دقيقتان)

1. في الهاتف اضغط **«امسح الرمز»**، ثم سجّل باسم ورقم مثل `0917778899`.
2. اضغط **«ربط عبر واتساب»**.
3. اسحب شريط المسافة إلى داخل النطاق (أقل من 150 م)، أو اضغط زر المرور.
4. اضغط الإشعار في شاشة القفل لترى العرض والعد التنازلي، ثم **«اعرضه على الكاشير واستخدمه»**.
5. غيّر حالة المحل إلى **«زحمة»** أو فعّل **وضع الشلة** وأعد التجربة لترى الفرق في الرسالة.

> **نصيحة للعرض:** افتح الرابط في تبويبين: واحد للوحة الكاشير وواحد للهاتف. أي تغيير في تبويب يظهر في الآخر.

لمسح كل البيانات والرجوع للبيانات التجريبية: زر **«مسح بيانات العرض»** في الأعلى.

## كيف يعمل السياج الجغرافي (Geofencing)

1. نحدد موقع الزبون: من GPS الحقيقي، أو من الشريط (نحوّل المسافة إلى إحداثيات).
2. نحسب المسافة بين المحل والزبون بـ **معادلة هافرساين (Haversine)**، لأن الأرض كروية:

```
a = sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2)
c = 2·atan2(√a, √(1−a))
d = R·c      (R = 6,371,008.8 م)
```

3. نرسل التنبيه **لحظة الدخول فقط** (من خارج النطاق إلى داخله)، وليس كل ثانية.
4. لا نكرر العرض إذا كان عند الزبون عرض نشط.

## التقنيات

- HTML5 + CSS3 (Grid / Flexbox / CSS Variables) + JavaScript ES6+، بدون أي أدوات بناء.
- واجهة عربية **RTL** بخط **Tajawal**.
- **HTML5 Geolocation API** للموقع الحقيقي.
- **Web Audio API** لصوت التنبيه.
- **localStorage** لحفظ الزبائن والإعدادات والسجل، مع مزامنة بين التبويبات.
- مكتبة [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (رخصة MIT) مضمّنة داخل الملف، فالنموذج يعمل حتى بدون إنترنت (عدا الخط).

## التشغيل محلياً

لا يحتاج تثبيت أي شيء: نزّل `index.html` وافتحه في المتصفح.

> ملاحظة: بعض المتصفحات لا تسمح بالموقع الحقيقي (GPS) إلا عبر `https`، لذلك جرّبه من رابط GitHub Pages.

## حدود هذا النموذج

هذا نموذج للعرض والتجربة، وليس منتجاً جاهزاً:

- **لا يوجد خادم:** البيانات محفوظة في متصفحك فقط.
- **واتساب والإشعارات محاكاة:** الإرسال الحقيقي يحتاج WhatsApp Business API وموافقة الزبون وقوالب رسائل معتمدة.
- **التتبع في الخلفية:** صفحة الويب لا تتابع الموقع وهي مغلقة. المنتج الحقيقي يحتاج تطبيقاً، أو بطاقات Wallet مرتبطة بموقع المحل.
- **بطاقة المحفظة محاكاة:** إصدار بطاقة Apple/Google Wallet حقيقية يحتاج حسابات مطوّر وتوقيع البطاقات من الخادم.
